## Lightbulb AR

A simulation of the lightbulb, battery, and switch experiment in AR, built with AR.js, Three.js, and Three.interactive. I built the project on top of the [Three.js boilerplate example](https://github.com/AR-js-org/AR.js/blob/master/three.js/examples/boilerplate-threejs.html) in AR.js's repository.
